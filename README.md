## Excel出力時の一時ブック方式

任意の一部シートだけを成果物として保存する場合、シート単体の `ws.Copy` ではコピー先にシートモジュールだけが残り、元ブックの標準モジュールや未選択シートが存在しない状態になることがあります。
その状態で `Worksheet_Change`、`Worksheet_Activate`、`Worksheet_Calculate` などのイベントや、UDF を含む再計算が実行・コンパイルされると、未定義の定数・関数、未選択シート参照、マスタシート参照などにより出力エラーになる可能性があります。

現在のExcel出力では、空ブックへセルを貼り直す方式ではなく、元ブック全体を `SaveCopyAs` で一時コピーし、その一時ブックを加工して `xlOpenXMLWorkbook` の `.xlsx` として保存します。これにより、図形・画像・テキストボックス・ページ設定・印刷範囲・列幅・行高・結合セルなど、テンプレートブックの見た目をできるだけ自然に保持します。

出力中は次の Application 状態を保存し、処理中だけ一時変更して、正常終了・エラー終了のどちらでも元の値へ戻します。

- `Application.EnableEvents`
- `Application.ScreenUpdating`
- `Application.DisplayAlerts`
- `Application.Calculation`

出力中は以下の状態にします。

```vba
Application.EnableEvents = False
Application.ScreenUpdating = False
Application.DisplayAlerts = False
Application.Calculation = xlCalculationManual
```

対象範囲は、元ブック全体の一時コピー作成、一時ブックのオープン、対象シートの表示、値貼り付け時の数式値化と選択外シート削除、関数保持時の選択外シートVeryHidden化、`xlOpenXMLWorkbook` 形式での `SaveAs`、一時ブックの `Close`、一時ファイル削除までです。
`ws.Copy` はExcel出力の主処理では使用しません。また、VBProject / VBComponents を操作してコードを削除する方式も使用しません。

### 対象関数

今回の制御は、次の実処理に実装しています。日本語名ラッパーが英数字名へ委譲している場合は、二重実装を避けるため実処理側のみで制御します。

| 出力種別 | 対象関数 | 変更理由 |
| --- | --- | --- |
| 単一シート・値貼り付け | `Excel_出力実行` | 元ブック全体の一時コピー上で対象シートを値化し、対象外シートを削除するため |
| 複数シート・値貼り付け | `Excel_MultiSheetExport`（`Excel_複数シート出力実行` から委譲） | 対象シートを先に値化してから対象外シートを削除し、参照切れや結合セルエラーを避けるため |
| 単一シート・関数保持 | `Excel_出力実行_関数保持` | 対象シートを表示し、参照元になり得る対象外シートを削除せず `xlSheetVeryHidden` で残すため |
| 複数シート・関数保持 | `Excel_複数シート出力実行_関数保持` | 選択対象外シートを非表示で残し、数式参照を壊しにくくするため |

## 値貼り付けモードと関数保持モード

- 値貼り付けモードでは、対象シートを表示状態にし、対象シート上の数式セルだけを `ConvertSheetFormulasToValuesSafely` で値化してから、選択外のシートを一時コピーから削除します。非選択のワークシートだけでなく、選択できないChartシート等も成果物に残しません。元ブックは変更しません。
- 値貼り付けモードの数式値化では、結合セルの左上セルだけを処理し、元シート上で空白に見える数式セルは空白として確定します。書式・結合・印刷設定は一時コピー内の選択シートを加工するため維持されます。
- 関数保持モードでは数式を保持します。選択したワークシートは表示状態にし、選択外のシートは削除せず `xlSheetVeryHidden` で保持します。そのため、数式が未選択シートを参照している場合でも参照先を維持できます。
- 値貼り付け出力でブック構造保護によりシートの表示変更・削除ができない場合は、エラーとして中止します。処理対象は一時コピーのため、元ブックは変更されません。
- どちらのモードも最終保存形式は `.xlsx` です。保存形式によりVBAコードは成果物に残らないため、出力ファイルを開いたときの `RYOHI_REASON_CELL` 未定義などのVBAコンパイルエラーを防ぎます。

## 実機確認について

Excel 16.0上で専用ダミーブックを使い、変更した数式値化・シート削除のVBA補助プロシージャを一時VBAプロジェクトに取り込んで実行しました。数式値化、可視/Hidden/VeryHidden/Chartシートの選択外削除、結合セル・印刷範囲の維持、元ブック無変更を確認しています。これは補助プロシージャの実機検証であり、UserFormを含むアドイン全体のコンパイル・統合動作を確認したものではありません。

職場環境へ反映する前に、専用のダミーブックで以下を確認してください。

1. シート一覧に `xlSheetVisible` のワークシートだけが表示され、Hidden/VeryHiddenが除外されること。
2. 再読込後も同じ表示条件になること。
3. 値貼り付けの単一/複数シート出力で、選択シートだけが残り、選択外ワークシートやChartシートが残らないこと。
4. 値貼り付け出力で数式が値化され、空白表示の数式が不要に `0` にならないこと。
5. 関数保持出力で選択シートは表示、選択外シートはVeryHiddenとなり、数式参照が維持されること。
6. 書式、図形・画像、列幅、行高、結合セル、印刷範囲、ページ設定が維持されること。
7. 元ブックが変更されず、一時ファイルが残らないこと。
8. ブック構造保護やエラー時に安全に中止し、Application設定が復元されること。
9. 対象ブック誤認識対策、PDF出力、印刷、プリセットが従来どおり動作すること。

## 印刷方式の切替

複数シートの印刷時に、フォーム上で次の方式を選べます。

- **シート別印刷（既定）**: フォームのシート一覧順に各ワークシートの `Worksheet.PrintOut` を個別に呼び出します。
- **まとめて印刷**: 従来どおり、対象ブックで選択したシート群に対して `SelectedSheets.PrintOut` を呼び出します。
- **単一シート**: どちらの選択でも1シートを印刷し、開始・終了ページの指定を維持します。

シート別印刷の呼び出し件数と印刷順はコード上で確認できますが、実際のジョブ分離や用紙への出力結果はプリンタードライバーに依存するため、仮想プリンター等での実機確認が必要です。印刷途中にエラーが起きた場合は正常終了した呼び出し件数を表示し、印刷を自動再送信しません。塗りつぶしとApplication設定の復元を行い、復元を確認できなかった場合は通知します。

### フォームのコントロール設定

既存の `frmPdfExport` に、デザイン画面で以下の2つを手動追加してください。両方を同じコンテナーに配置し、同じ `GroupName` に設定します。

| 種類 | Name | Caption | GroupName | Value |
| --- | --- | --- | --- | --- |
| `MSForms.OptionButton` | `optPrintSeparate` | `シート別印刷` | `grpPrintMode` | `True` |
| `MSForms.OptionButton` | `optPrintCombined` | `まとめて印刷` | `grpPrintMode` | `False` |

コードでもフォーム初期化のたびに `grpPrintMode` と既定値を設定します。印刷方式はフォームを閉じるまで保持し、次回起動時はシート別印刷に戻ります。フォームのコントロールをVBAで動的生成する処理はありません。

### 既存フォームへの反映手順

このリポジトリにある `frmPdfExport.txt` はUserFormのコードビハインドです。UserFormのデザイン定義（`.frm` / `.frx`）は管理されていないため、フォームを削除・再作成したり、デザインを再構築したりしないでください。

1. 職場PCのアドインと既存フォームをバックアップします。
2. 既存の `frmPdfExport` のデザイン画面に上表の2つのOptionButtonを追加し、プロパティを設定します。
3. VBEで既存 `frmPdfExport` のコード画面を開き、GitHub版 `frmPdfExport.txt` の内容でコードビハインドを置き換えます。フォーム本体は維持してください。
4. VBEの「デバッグ」→「VBAProjectのコンパイル」を実行します。
5. 機密情報を含まないダミーブックと仮想プリンターを使い、複数シートの両方式、単一シートのページ範囲、塗りつぶし復元、途中エラー時の通知を確認します。
6. 問題がなければアドインを保存します。共有アドイン本体への反映は職場PC側で行います。

今回の静的テストはVBAソースを検査するものであり、UserFormデザイン、VBAコンパイル、実際のプリンター出力を代替しません。
